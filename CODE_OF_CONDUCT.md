# Code of Conduct

## Our Standards

This is a portfolio / research project. Interactions are expected to be professional and constructive.

- Use welcoming and inclusive language.
- Be respectful of differing viewpoints and experience levels.
- Accept constructive criticism gracefully.
- Focus on what is best for the project and its technical integrity.

## Unacceptable Behaviour

- Harassment, personal attacks, or discriminatory language of any kind.
- Publishing private information (email addresses, etc.) without consent.
- Conduct that would be inappropriate in a professional setting.

## Scope

This Code of Conduct applies to all project spaces: GitHub issues, pull requests, discussions, and any other forum where the project is represented.

## Reporting

Report concerns to `nikunjhardik2006@gmail.com`. All reports will be reviewed and responded to promptly.
